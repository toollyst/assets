# Toollyst assets

Images for Toollyst sites, served through jsDelivr so our hosts never serve heavy files:

```
https://cdn.jsdelivr.net/gh/toollyst/assets@<tag>/<path>
```

Files under a tag never change. To publish new or changed files, commit them and push a new tag (`v2`, `v3`, …), then point the site at it.

- `photo/samples/` — the Samples tab of photo.toollyst.com: a source photo and a preview of the preset's result.

See [CREDITS.md](CREDITS.md) for where the photos come from.
